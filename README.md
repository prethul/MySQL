## 🚀 How to Run

1. Install [MySQL](https://dev.mysql.com/downloads/) (and optionally MySQL Workbench).
2. Clone the repository:
   ```bash
   git clone https://github.com/prethul/MySQL.git
   cd MySQL
   ```
3. Open MySQL and run any script:
   ```bash
   mysql -u root -p < "SQL-1.sql"
   ```
   Or open the file in MySQL Workbench and click **Execute**.
